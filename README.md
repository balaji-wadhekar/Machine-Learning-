# Machine Learning Projects

A collection of foundational Machine Learning implementations, starting with Linear Regression.

## 📌 Features
- **Linear Regression from Scratch:** Core math, cost function (MSE), and gradient descent using pure NumPy.
- **Scikit-Learn Implementation:** Production-ready training, testing, and evaluation pipeline.
- **Visual Diagnostics:** Actual vs. Predicted plots and Residual error distributions via Matplotlib and Seaborn.

## 🛠️ Tech Stack & Libraries
- Python 3
- NumPy
- Pandas
- Scikit-Learn
- Matplotlib & Seaborn
- Jupyter Notebook (`ipykernel`)
